# Fidel Gonzalez Leiva - CV

Personal professional CV written in LaTeX.

## Build

Install a LaTeX distribution with `pdflatex`, then run:

```sh
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

This generates `main.pdf` in the project directory.
